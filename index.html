ABOUT OUR PROGRAM

ข้อมูลรายละเอียดหลักสูตรเชิงกลยุทธ์

โครงสร้างเชิงเป้าหมาย ผลลัพธ์การเรียนรู้ และทิศทางเพื่อสร้างบัณฑิตที่ตอบโจทย์อนาคต

"เชี่ยวชาญด้านวิทยาการคอมพิวเตอร์ มีคุณธรรม นำนวัตกรรมเพื่อพัฒนาท้องถิ่น"

ปรัชญานี้สะท้อนอัตลักษณ์สำคัญ 3 ด้าน ได้แก่ ความเชี่ยวชาญในวิชาชีพคอมพิวเตอร์ การมีคุณธรรมจริยธรรมวิชาชีพ และการพัฒนานวัตกรรมนำไปใช้พัฒนาท้องถิ่น ซึ่งเชื่อมโยงโดยตรงกับวิสัยทัศน์พันธกิจเพื่อการร่วมขับเคลื่อนสังคมของมหาวิทยาลัยราชภัฏ

เชี่ยวชาญวิชาชีพ

ฝึกฝนทักษะการเขียนโปรแกรม โครงสร้างข้อมูล อัลกอริทึม และระบบฐานข้อมูลระดับเข้มข้น

คุณธรรมจริยธรรม

ยึดมั่นในจรรยาบรรณวิชาชีพไอที เคารพกฎหมายทรัพย์สินทางปัญญา และ พ.ร.บ. คอมพิวเตอร์

นวัตกรรมสู่ท้องถิ่น

สร้างสรรค์โครงงานและแอปพลิเคชันที่ช่วยแก้ปัญหาและยกระดับเศรษฐกิจชุมชนจริง

วิสัยทัศน์ที่เกี่ยวข้อง

มุ่งร่วมเป็นกำลังสำคัญขับเคลื่อนมหาวิทยาลัยให้เป็น "สถาบันอุดมศึกษาแห่งการเรียนรู้ตลอดชีวิต" (Lifelong Learning)

1. ผลิตบัณฑิตคุณภาพ

สร้างบัณฑิตที่มีทักษะความรู้ด้านวิทยาการคอมพิวเตอร์และเทคโนโลยีขั้นสูง พร้อมทำงานจริงในทุกองค์กร

2. วิจัยและนวัตกรรม

ส่งเสริมวิชาการ ค้นคว้าวิจัยประยุกต์ และพัฒนานวัตกรรมซอฟต์แวร์สอดคล้องกับท้องถิ่น

3. บริการวิชาการท้องถิ่น

พัฒนาสมรรถนะนักศึกษาในการเรียนรู้ร่วมกับสังคม ก้าวสู่วิศวกรสังคมที่มีหัวใจบริการ

4. คุณธรรมและกฎหมาย

หล่อหลอมความซื่อสัตย์สุจริต และปฏิบัติตามจรรยาบรรณวิชาชีพนักไอทีอย่างมั่นคง

เป้าหมาย 1
ความรู้ความเชี่ยวชาญเฉพาะด้าน: มีความรู้และทักษะเฉพาะด้านในสาขาวิทยาการคอมพิวเตอร์อย่างลึกซึ้ง สามารถออกแบบ พัฒนา และบำรุงรักษาระบบซอฟต์แวร์ทั้งออนไลน์และออฟไลน์
เป้าหมาย 2
การประยุกต์สร้างนวัตกรรม: มีทักษะในการประยุกต์ใช้วิธีวิทยาและเทคโนโลยีในการพัฒนางานวิจัย โครงงานนวัตกรรม เพื่อสร้างมูลค่าทางเศรษฐกิจให้แก่ชุมชน
เป้าหมาย 3
การคิดเชิงระบบ: วิเคราะห์และประมวลองค์ความรู้ทางเทคนิคแบบบูรณาการ เพื่อวางแผนจัดสรรกระบวนการทางคอมพิวเตอร์แก้ปัญหาเชิงซ้อนได้อย่างเป็นระบบ
เป้าหมาย 4
คุณธรรมจริยธรรม: ยึดมั่นในการประพฤติตนเป็นคนดีมีระเบียบวินัย ปฏิบัติตามจรรยาบรรณวิชาชีพ พร้อมมนุษยสัมพันธ์และการทำงานเป็นทีม
PLO 1 ประยุกต์ใช้ความรู้ด้านวิทยาการคอมพิวเตอร์เพื่อแก้ปัญหาและสนับสนุนการทำงานด้วยระบบคอมพิวเตอร์
PLO 2 พัฒนาระบบด้วยภาษาโปรแกรมต่าง ๆ ในรูปแบบออฟไลน์และออนไลน์ ตามเกณฑ์มาตรฐานสากล
PLO 3 พัฒนาแอปพลิเคชันบนอุปกรณ์พกพา (Mobile App) ตรงตามความต้องการของผู้ใช้งาน
PLO 4 ทดสอบคุณภาพการทำงานของซอฟต์แวร์ตามกระบวนการ Software Testing ได้อย่างถูกต้อง
PLO 5 พัฒนานวัตกรรมด้านเทคโนโลยีคอมพิวเตอร์ที่สอดคล้องกับความต้องการของชุมชนและหน่วยงานท้องถิ่น
PLO 6 แสดงออกถึงกระบวนการคิดเชิงระบบ ความเป็นมืออาชีพ มีความอดทน มุ่งมั่น และรับผิดชอบสูง
PLO 7 ตระหนักและประยุกต์ใช้หลักจรรยาบรรณวิชาชีพ คุณธรรม และจริยธรรมตาม พ.ร.บ. คอมพิวเตอร์

SPECIALIZATION TRACKS

โครงสร้างกลุ่มวิชาความเชี่ยวชาญ

ออกแบบหลักสูตรให้ครอบคลุม 3 ด้านหลักที่ตลาดแรงงานไอทีระดับสากลต้องการสูงสุด

โครงข่ายคอมพิวเตอร์ (Networks)

เรียนรู้การออกแบบ ติดตั้ง และบำรุงรักษาระบบเครือข่าย ทั้งแบบสายและไร้สายเพื่อการสื่อสารในองค์กร

มีห้องแล็บ 3 หน่วยกิต

ความปลอดภัยของข้อมูล (Security)

การป้องกันและควบคุมความปลอดภัยข้อมูล การเข้ารหัสลับ และการตรวจจับผู้บุกรุกในระบบสารสนเทศ

วิชาบรรยาย 3 หน่วยกิต

นิติวิทยาศาสตร์คอมพิวเตอร์ (Forensics)

การตรวจสอบและวิเคราะห์ข้อมูลที่ถูกโจมตีทางไซเบอร์ การสืบค้นพยานหลักฐานดิจิทัล และกฎหมายไอที

มีห้องแล็บ 3 หน่วยกิต

ระบบฐานข้อมูล (Database Systems)

การออกแบบ ติดตั้ง และบำรุงรักษาระบบฐานข้อมูล รวมถึง SQL ซึ่งเป็นภาษาคิวรีสำหรับฐานข้อมูล

มีห้องแล็บ 3 หน่วยกิต

วิศวกรรมซอฟต์แวร์ (Software Eng)

กระบวนการสร้างซอฟต์แวร์ การวิเคราะห์และออกแบบระบบ การทดสอบและการบำรุงรักษาตามมาตรฐาน

วิชาบรรยาย 3 หน่วยกิต

เว็บแอปพลิเคชันสมัยใหม่ (Modern Web)

การเขียนโปรแกรมฝั่งไคลเอนต์และเซิร์ฟเวอร์ด้วยเฟรมเวิร์กยอดนิยม เช่น React, Next.js และ Node.js

มีห้องแล็บ 3 หน่วยกิต

การประมวลผลภาพดิจิทัล (Image Processing)

การปรับแต่งภาพ การค้นหาวัตถุ และการสกัดคุณลักษณะจากภาพด้วยอัลกอริทึมคอมพิวเตอร์

มีห้องแล็บ 3 หน่วยกิต

สารสนเทศภูมิศาสตร์ (GIS)

การประยุกต์ใช้เทคโนโลยีสารสนเทศในการวิเคราะห์ แสดงผลข้อมูล และแผนที่ภูมิศาสตร์ขั้นสูง

มีห้องแล็บ 3 หน่วยกิต

ปัญญาประดิษฐ์ (Artificial Intelligence)

การพัฒนาเทคโนโลยีจำลองความฉลาดของมนุษย์ เช่น การประมวลผลภาษาธรรมชาติ (NLP)

วิชาบรรยาย 3 หน่วยกิต

การเขียนโปรแกรมวิทยาการข้อมูล

ปฏิบัติการเขียนโค้ดด้วยภาษา Python และ R เพื่อการสกัด ดึงข้อมูล และทำ Data Cleansing
